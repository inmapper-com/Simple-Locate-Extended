SimpleLocate — Log Görüntüleyici

JSON / gzip çöz · pin no · gösterge önizleme · simülasyon

Standart export JSON, CSV’den dönüştürülmüş dizi veya Cloud Logs payload_gz yapıştırılabilir. Konumlar haritada pin olarak görünür.

Kayıtlar Cloud SQL test_logs tablosundan Cloud Functions üzerinden gelir.

Aynı logun ham GPS’i aşağıdaki ayarlarla yeniden oynatılır. Cyan = kayıtta gördüğün yol, turuncu = bu ayarlar. Kesikli çizgiler: gösterim ham GPS’in ne kadar gerisinde (uzun = arkadan takip).

PDR/ivmeölçer replay edilmez. Yeşil hücre = lag / yetişme daha iyi. Dururken titreme ve max sıçrama artarsa konum daha sinirli demektir.

Pin seçilince test sırasında görünen konum noktası + accuracy çemberi çizilir. Varsayılanlar app.html ile aynı; burada değiştirebilirsin.
